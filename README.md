# ASIMOV Hugging Face Module

[![License](https://img.shields.io/badge/license-Public%20Domain-blue.svg)](https://unlicense.org)
[![Compatibility](https://img.shields.io/badge/rust-1.85%2B-blue)](https://blog.rust-lang.org/2025/02/20/Rust-1.85.0/)
[![Package](https://img.shields.io/crates/v/asimov-huggingface-module)](https://crates.io/crates/asimov-huggingface-module)

ASIMOV module for model downloads from the Hugging Face Hub platform.

## 🛠️ Prerequisites

- [Rust](https://rust-lang.org) 1.85+ (2024 edition)

## ⬇️ Installation

### Installation from Source Code

```bash
cargo install asimov-huggingface-module
```

## 👉 Examples

```console
$ asimov-huggingface-cataloger
```

## 👨‍💻 Development

```bash
git clone https://github.com/asimov-modules/asimov-huggingface-module.git
```
